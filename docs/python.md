## Installation
```bash
sudo apt install python3-venv -y
```
## Création d'un environnement
```bash
python3 -m venv venv
```
## Activation de l'environnement
```bash
source venv/bin/activate
```

Vous devez avoir : (venv) user@machine:~

## Désactivation
```bash
deactivate
```
